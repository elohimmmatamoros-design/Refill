# Refill — mockup móvil

Proyecto de Refill listo para abrir y editar en Visual Studio Code.

## Cómo abrirlo

1. Descomprime el archivo ZIP.
2. Abre Visual Studio Code.
3. Selecciona **File > Open Folder** y abre la carpeta `Refill_VSCode`.
4. Abre la terminal integrada con **Terminal > New Terminal**.
5. Ejecuta:

```bash
npm install
npm run dev
```

6. Abre en tu navegador la dirección que aparezca en la terminal, normalmente `http://localhost:5173`.

## Archivos principales

- `app/page.tsx`: contenido, pantallas e interacciones.
- `app/globals.css`: diseño, colores y adaptación para celular.
- `app/layout.tsx`: título y configuración general.
- `public/og.png`: imagen de presentación de Refill.

## Funciones del mockup

- Carga demostrativa de una fotografía de factura.
- Inventario editable con cantidades y precios.
- Registro manual de productos.
- Sugerencias de recetas con IA simulada.
- Ingredientes faltantes con precios aproximados.
- Comparación demostrativa de supermercados y delivery.
- Tips para conservar alimentos, incluido el culantro.

> Nota: la inteligencia artificial, los precios, el inventario y el delivery son simulaciones creadas para fines académicos.
